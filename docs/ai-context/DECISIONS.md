# ثبت تصمیمات معماری و اصلاحات (Architectural Decisions) — مای‌سایت

## ۱. بازنویسی با DRF و حذف تمپلیت‌تگ‌های جنگو
- **تصمیم**: رندر HTML توسط جنگو متوقف می‌شود و به یک ساختار Headless API مبتنی بر DRF تبدیل می‌گردد.
- **دلیل**: تسهیل اتصال به فرانت‌اندهای مدرن، واکنش‌گرایی سریع‌تر، و امکان توسعه مستقل فرانت‌اند.

## ۲. مهاجرت پایگاه داده به PostgreSQL
- **تصمیم**: جایگزینی دیتابیس فایل‌محور SQLite با سرور دیتابیس رابطه‌ای PostgreSQL.
- **دلیل**: امنیت بالا، پشتیبانی بهتر از هم‌زمانی و یکپارچگی زیرساخت با پروژه شعرخانه.

## ۳. انتخاب فریم‌ورک فرانت‌اند با اولویت سئو
- **تصمیم**: استفاده از Next.js به جای SPA تک‌صفحه‌ای ساده (React خام) در فرانت‌اند نهایی.
- **دلیل**: چون پورتفولیو و وبلاگ شخصی باید در گوگل و موتورهای جستجو ایندکس شوند، رندر سمت سرور (SSR/SSG) در Next.js ضروری است.

## ۴. اصلاح پالت رنگی و استایل گلس‌مورفیسم
- **تصمیم**: اصلاح تم رنگی اولیه و حرکت به سمت طیف‌های مدرن، متین و تیره‌رنگ همراه با افکت‌های مات و شیشه‌ای (پچ اولیه `frontend-glass-redesign.patch` در ریشه پروژه ثبت شده است).
