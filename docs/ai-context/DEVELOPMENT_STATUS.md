# وضعیت واقعی پیاده‌سازی و آزمون‌ها — مای‌سایت

## ۱. قابلیت‌های پیاده‌سازی‌شده و مستقر
- [x] بازطراحی ساختار مدل‌ها با تفکیک معنایی (`Technology`, `Skill`, `Project`, `Profile`, `BlogPost`).
- [x] مایگریشن شماره ۱۸ (افزودن فیلدها و مدل فناوری)، مایگریشن شماره ۱۹ (انتقال خودکار داده‌ای رکوردهای قدیمی با اسلاگ‌های یکتا، حفظ demo_url خالی و تفکیک فناوری‌ها) و مایگریشن شماره ۲۰ (قید دیتابیسی تک‌رکوردی پروفایل و تمیزسازی پیش‌فرض‌ها).
- [x] پیاده‌سازی سریالایزرهای استاندارد با اعتبارسنجی تمیز و فیلد هانی‌پات ضد اسپم در `website/serializers.py`.
- [x] پیاده‌سازی ویوست‌های فقط‌خواندنی عمومی و اندپوینت دریافت پیام در `website/api_views.py`.
- [x] کلاس‌های تراتلینگ دولایه برای کنترل هرزنامه در `website/throttles.py`.
- [x] ماژول امنیتی استخراج امن نشانی کلاینت متناسب با لودبالانسر Render و هش آی‌پی با HMAC-SHA256 در `website/security.py`.
- [x] مدیریت خطای ۴۰۴ استاندارد در واکشی پروژه‌ها بر اساس اسلاگ و شناسه عددی.
- [x] فیلتر کامل مقالات در وضعیت Published در ویوهای سنتی (`home_view` و `blog_detail`) و بازگرداندن وضعیت ۴۰۴ برای مقالات پیش‌نویس (Draft).
- [x] بهینه‌سازی واکشی پروژه‌ها با `prefetch_related("technologies")` جهت پیشگیری از کوئری‌های تکراری N+1.
- [x] حفظ ۱۰۰٪ کارکرد تمپلیت‌های سنتی `home.html` و `blog_detail.html` و پورتفولیو نبیولا ۲.
- [x] ۲۳ آزمون خودکار سراسری در `website/tests.py` شامل اجرای واقعی مایگریشن با `MigrationExecutor`، آزمون‌های امنیتی آی‌پی، آزمون‌های دیتابیسی تک‌رکوردی بودن پروفایل و تست‌های رندر تمپلیت با وضعیت قبولی ۱۰۰٪.
