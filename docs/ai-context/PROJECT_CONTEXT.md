# معرفی و محدوده واقعی پروژه مای‌سایت (MySite)

## ۱. هویت و ماهیت پروژه
پروژه «مای‌سایت» وب‌سایت رسمی پورتفولیو، رزومه تعاملی و وبلاگ شخصی مهندس است. این پروژه بر پایه فریم‌ورک جنگو پیاده‌سازی شده و هدف آن ارائه پایدار، سریع و امن مهارت‌ها، سوابق تحصیلی، پروژه‌ها و مقالات فنی است.

## ۲. محدوده واقعی مأموریت (Real Project Scope)
هدف پروژه در این مرحله، توسعه یک محصول جدید، پیچیده‌سازی معماری یا بازنویسی بی‌مورد فرانت‌اند نیست؛ بلکه تمرکز مطلق بر موارد زیر است:
*   **بهینه‌سازی مهندسی بک‌اند**: ساختار تمیز، قابل نگهداری و استاندارد در پایتون و جنگو.
*   **پیاده‌سازی اصولی رست فریم‌ورک**: ارائه اندپوینت‌های استاندارد نسخه یک (`/api/v1/`) با سریالایزرها و ویوست‌ها.
*   **بهبود طراحی مدل‌ها و دیتابیس**: تفکیک معنایی فناوری‌های پروژه از مهارت‌های فردی، اسلاگ‌های یکتا و خودکار، و تضمین تک‌رکوردی بودن پروفایل.
*   **حفظ ۱۰۰٪ هویت و فرانت‌اند موجود**: قالب‌های تمپلیت فعلی، سیستم طراحی سی‌اس‌اس ماژولار نبیولا ۲، اسکریپت‌های حرکتی جاوااسکریپت و فیلترهای تمپلیت‌تگ بدون تغییر و کاملاً سالم و فعال باقی می‌مانند.
*   **امنیت و تست‌پذیری**: تراتلینگ، هانی‌پات ضد اسپم، اعتبارسنجی ورودی‌ها و آزمون‌های خودکار سراسری.
