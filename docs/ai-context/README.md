# راهنمای مستندات حافظه هوش مصنوعی — پروژه مای‌سایت (MySite)

این پوشه شامل مستندات استخراج‌شده از تاریخچه تحلیل‌ها، تصمیمات معماری، وضعیت توسعه و اهداف نوسازی وب‌سایت شخصی و پورتفولیوی «مای‌سایت» است.

## ترتیب مطالعه برای Agent
1. [PROJECT_CONTEXT.md](./PROJECT_CONTEXT.md): معرفی ماهیت پروژه، اهداف رزومه و نیازمندی‌های سئو.
2. [ARCHITECTURE.md](./ARCHITECTURE.md): معماری فعلی (جنگو یکپارچه) در برابر معماری هدف (DRF + Next.js + PostgreSQL).
3. [DEVELOPMENT_STATUS.md](./DEVELOPMENT_STATUS.md): وضعیت قابلیت‌های موجود و برنامه نوسازی.
4. [DECISIONS.md](./DECISIONS.md): تصمیمات فنی ثبت‌شده برای گذر از تمپلیت‌های سنتی به API مدرن.
5. [LEARNING_CONTEXT.md](./LEARNING_CONTEXT.md): مفاهیم فنی مرتبط با مهاجرت به معماری جداگانه (Decoupled).
6. [CONVERSATION_INDEX.md](./CONVERSATION_INDEX.md): مکالمات انجام‌شده در Antigravity درباره این پروژه.
7. [OPEN_QUESTIONS.md](./OPEN_QUESTIONS.md): تصمیمات طراحی، پالت رنگی و استراتژی دپلوی.
