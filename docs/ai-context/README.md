# راهنمای مستندات فنی و بافت هوش مصنوعی — پروژه مای‌سایت (MySite)

این پوشه شامل بافت واقعی و مستندات فنی استخراج‌شده از تصمیمات معماری، مدل‌های داده، وضعیت پیاده‌سازی و استانداردهای کیفی پروژه وب‌سایت شخصی و پورتفولیوی «مای‌سایت» است.

## ترتیب مطالعه:
1. [PROJECT_CONTEXT.md](./PROJECT_CONTEXT.md): معرفی ماهیت پروژه و محدوده قطعی بازطراحی بک‌اند.
2. [ARCHITECTURE.md](./ARCHITECTURE.md): معماری دوگانه و پایدار (حفظ تمپلیت‌های نبیولا ۲ در کنار لایه REST API).
3. [DECISIONS.md](./DECISIONS.md): تصمیمات مهندسی ثبت‌شده درباره مدل‌ها، امنیت و تفکیک دامنه‌ها.
4. [DEVELOPMENT_STATUS.md](./DEVELOPMENT_STATUS.md): وضعیت قابلیت‌های پیاده‌سازی‌شده و نتایج آزمون‌های خودکار.
5. [LEARNING_CONTEXT.md](./LEARNING_CONTEXT.md): نکات فنی و تجربیات بهینه‌سازی بک‌اند جنگو.
6. [CONVERSATION_INDEX.md](./CONVERSATION_INDEX.md): نمایه تاریخچه مکالمات توسعه پروژه.
